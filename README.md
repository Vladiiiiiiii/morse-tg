# Телеграфный тренажёр — сборка для Telegram

Отдельная копия сайта, упакованная как **Telegram Mini App**.
Основная версия лежит в `../morze-main` и этой сборкой не затрагивается.

## Что отличается от основной версии

| Файл | Что изменено |
|---|---|
| `telegram.js` | новый файл: обвязка Telegram (хранилище, вьюпорт, вибро, кнопка «Назад») |
| `index.html` | подключены `telegram-web-app.js` и `telegram.js`; высота зоны ввода считается от вьюпорта Telegram; вибро при нажатии ключа; уведомление обвязки о смене вкладки |
| `stories/` | без изменений |

Конкретно:

- **Прогресс в облаке.** Игра читает прогресс через `window.storage`; `telegram.js` подменяет его на
  `CloudStorage` Telegram, поэтому пройденные уровни следуют за аккаунтом на любом устройстве.
  `localStorage` остаётся зеркалом и запасным вариантом.
- **Свайп вниз не закрывает игру** — вызывается `disableVerticalSwipes()`. Без этого нижняя зона
  ввода конфликтует с жестом закрытия Mini App.
- **Высота экрана** берётся из `viewportStableHeight`, а не из `100vh` — внутри Telegram это разные величины.
- **Вибро** (`HapticFeedback`) на каждое нажатие телеграфного ключа.
- **Системная кнопка «Назад»** появляется вне вкладки «ИСТОРИИ» и возвращает к списку историй.
- Цвет шапки и фона приложения выставляется под тёмную палитру игры.

Вне Telegram (обычный браузер) вся обвязка отключается сама, страница работает как раньше.

## Ограничения облачного хранилища

- Ключи Telegram допускают только `A-Z a-z 0-9 _ -`, поэтому `level_stats:story:1`
  превращается в `level_stats_story_1`.
- Значение больше 4096 символов в облако не пишется — такая запись остаётся только в `localStorage`.
  На практике это очень длинная история попыток одного уровня.
- Если облако не отвечает 2.5 секунды или возвращает ошибку, оно выключается на всю сессию,
  чтобы загрузка не вставала на таймаутах (прогресс читается по одному ключу на уровень).

## Локальная проверка

Любой статический сервер из корня этой папки, например:

    python3 -m http.server 8793

и открыть `http://localhost:8793`. Истории подтягиваются из `stories/` только по http(s),
при открытии файла напрямую (`file://`) останется одна встроенная история.

## Скорость загрузки

Прогресс хранится по одному ключу на уровень — это 250+ чтений на экране «ИСТОРИИ».
По одному запросу в облако это давало 10–20 секунд ожидания, поэтому `telegram.js`
на старте выгружает всё разом (`getKeys` + `getItems` пачками по 40) и дальше отдаёт
из памяти: 3 обращения к облаку вместо 259.

Если облако не ответит за 3.5 секунды, оно отключается на сессию и игра работает
на `localStorage`.

Файлы историй грузятся параллельно, а список историй рисуется сразу — прогресс
в карточках дозаполняется следом.

**При обновлении на хостинге** увеличивай версию в `<script src="telegram.js?v=N">`:
Telegram кэширует статику агрессивно, без смены адреса пользователи получат старый файл.
